CAMPUS LENS — FRONT END WEB DESIGN AND DEVELOPMENT PROJECT

Files:
- index.html: Home page
- student-guide.html: student guide and sample timetable table
- register.html: student registration form with validation
- lab.html: JavaScript practical exercises and frame-style navigation
- style.css: shared styling, selectors, box model, responsive layout
- script.js: DOM, variables, functions, events, loops, validation and built-in objects

HOW TO RUN:
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a modern browser.
4. Internet access is not required for the core website.

IMPORTANT:
- This is a front-end educational demo. Forms do not transmit/store information.
- Sample events and timetable entries are illustrative, not official college information.
- The syllabus refers to frames; frameset is obsolete in modern HTML. lab.html demonstrates a modern two-panel equivalent.
- Replace institution-specific details and screenshots if your instructor requires an official cover format.
